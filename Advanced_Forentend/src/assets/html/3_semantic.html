What are Semantic Elements?

Semantic elements describe meaning to both the browser and developer. Examples: <header>, <article>, <footer>, <nav>.

HTML4 vs HTML5

Feature HTML4 HTML5
Structure Tags Only <div> and <span> header, nav, section, article, aside, footer
Multimedia Needed plugins (Flash) Built-in <video> and <audio>
Form Inputs text, password, etc. email, date, range, color, tel, etc.
Offline Support Not supported LocalStorage, AppCache

Span vs Div

div: Block-level. Takes full width. Used to group sections of a page.

span: Inline. Only takes width of content. Used to style small parts of text.

Example: The word blue is styled with a span.
