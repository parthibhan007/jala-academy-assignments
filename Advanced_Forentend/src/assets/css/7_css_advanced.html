display vs visibility

display: none – The element is completely removed from the layout (takes no space).

visibility: hidden – The element is invisible but still takes up space in the layout.

display: none example:

Box 1 (visible)
Box 2 (hidden)
Box 3 (visible)

Box 2 is display:none — it's gone from the layout completely.

visibility: hidden example:

Box A (visible)
Box B (hidden)
Box C (visible)

Box B is visibility:hidden — the gap/space is still there.

Padding and Margin

Padding is space inside the element (between content and border).

Margin is space outside the element (between element and neighbors).

This div has: margin: 30px; padding: 20px;
This div has extra padding: 30px so the content area feels spacious.
