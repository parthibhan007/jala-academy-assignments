CSS Position Properties

The container below shows static, relative, and absolute positioning:

static relative (top:10, left:10) absolute (top:10, right:10)

static: Default. No special positioning.
relative: Positioned relative to itself.
absolute: Positioned relative to nearest positioned ancestor.
fixed: Stays at the same screen position even when scrolling.
sticky: Sticks when scrolled to a threshold (see sticky bar at top).
