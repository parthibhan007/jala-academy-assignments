About DOM, Events, and MySQL

DOM

The Document Object Model is a tree structure of all HTML elements. JavaScript and AngularJS can read and modify it.

Events

Events are actions triggered by users (click, hover, input). AngularJS handles them with directives like ng-click and ng-mousemove.

MySQL

MySQL is a relational database. It stores data in tables. Frontend apps call a backend API (like PHP/Node.js) which queries MySQL.
