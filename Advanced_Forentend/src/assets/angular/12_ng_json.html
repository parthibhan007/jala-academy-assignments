AngularJS JSON & ng-repeat

1. JSON Table with ng-repeat, $index, $odd, $even

<tr ng-repeat="s in students"
    ng-class="{'even-row': $even, 'odd-row': $odd}">
  <td>{{ $index + 1 }}</td>
  <td>{{ s.name }}</td>
  ...
</tr>

2. Sorting with Filters

<tr ng-repeat="s in students | orderBy:sortColumn:sortReverse">

$scope.sortColumn = "name";
$scope.sortReverse = false;

3. ng-options vs ng-repeat for Dropdown

<!-- ng-repeat in select -->
<select>
  <option ng-repeat="c in courses">{{ c }}</option>
</select>

<!-- ng-options (preferred for objects) -->
<select ng-model="selected" ng-options="c for c in courses">
</select>

Using ng-options (cleaner for objects):
Selected: {{ selectedCourse }}

Difference: ng-options binds the full object and is more performant. ng-repeat inside <option> gives string values and adds an empty first option.
