AngularJS Basics

1. AngularJS Expressions {{ }}

<p>{{ "Hello" + " World" }}</p>
<p>{{ 10 + 5 }}</p>
<p>{{ 100 / 4 }}</p>

String expression: {{ "Hello" + " World" }}

Math: 10 + 5 = {{ 10 + 5 }}

Division: 100 / 4 = {{ 100 / 4 }}

Scope variable: {{ greeting }}

2. ng-model – Two-Way Data Binding

<input type="text" ng-model="name" />
<p>Hello, {{ name }}!</p>
Hello, {{ name || "stranger" }}!
Double of {{ num || 0 }} = {{ (num || 0) * 2 }}

3. Controller and $scope

app.controller("StudentCtrl", function($scope) {
  $scope.student = {
    name: "Priya",
    course: "B.Tech",
    year: 3
  };
  $scope.showInfo = function() {
    $scope.message = "Student: " + $scope.student.name;
  };
});

Name: {{ student.name }}

Course: {{ student.course }}

Year: {{ student.year }}

{{ message }}
